# Marigold & Monsoon

A 14-page digital sketchbook: each photo sits on the left page and a hand-drawn ink-and-wash canvas sketch draws itself on the right.

- `index.html` — layout, navigation, sketch engine, page 1 sketch, lofi piano (Web Audio)
- `pages.js` — sketch recipes for pages 2–14
- `photos/`, `thumbs/` — images

Open `index.html` in a browser, or serve it with GitHub Pages.
